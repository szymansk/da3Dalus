# takeoff speed · `V_TO`

The named speed of an operating point: the speed at which the model gets away safely, above the stall speed in the take-off configuration. There is no generic
operating-point speed — each carries its point in its name (A2).

**Unit.** `m/s`

**Produced by.** [[speed-from-stall-margin]]

**Used by.** [[mass-envelope]]
