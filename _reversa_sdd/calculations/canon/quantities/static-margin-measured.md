# Static margin, measured · `SM_meas`

`(x_NP − x_CG)/c_MAC` — positive is stable; commonly quoted in % MAC. Computed from a given CG ([[centre-of-gravity-measured]]), not to be confused with [[static-margin-target]] (`SM_target`). No design result depends on it; it is the path for checking an existing design and later for flight calibration (BELEMNITOS).

**Unit.** `1`
